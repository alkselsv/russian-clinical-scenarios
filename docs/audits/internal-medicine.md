# Клинический аудит блока internal-medicine

> Статус всего блока: `unsafe-until-clinician-approved`. Это исследовательские сценарии, не медицинская инструкция.

Проверено 5 октября 2026 года. Сопоставление НМУ требует повторной сверки при обновлении ФР НСИ; `pending-nmu-review` не является кодом.

<a id="case-internal-medicine-0001"></a>
## case.internal-medicine.0001: Железодефицитная анемия на фоне обильных менструаций

- Итог: **critical-revision-required**.
- Ключевое исправление: исходная тактика не содержала ни железа, ни поиска причины кровопотери.
- Основание: guideline.ru.minzdrav.669.v2.

<a id="case-internal-medicine-0002"></a>
## case.internal-medicine.0002: Витамин-B12-дефицитная анемия с неврологическими проявлениями

- Итог: **critical-revision-required**.
- Ключевое исправление: выписка не лечила неврологически проявленный дефицит B12.
- Основание: guideline.ru.minzdrav.536.v3.

<a id="case-internal-medicine-0003"></a>
## case.internal-medicine.0003: Артериальная гипертензия с поражением органов-мишеней

- Итог: **major-revision-required**.
- Ключевое исправление: диагноз и лечение нельзя основывать на единичном измерении АД.
- Основание: guideline.ru.minzdrav.62.v3.

<a id="case-internal-medicine-0004"></a>
## case.internal-medicine.0004: Впервые выявленный сахарный диабет 2 типа

- Итог: **critical-revision-required**.
- Ключевое исправление: нужно исключить острую декомпенсацию и индивидуализировать стартовую терапию.
- Основание: guideline.ru.minzdrav.290.v2.

<a id="case-internal-medicine-0005"></a>
## case.internal-medicine.0005: Нетяжёлая внебольничная пневмония

- Итог: **critical-revision-required**.
- Ключевое исправление: неопределённый антибиотик широкого спектра заменён конкретной амбулаторной тактикой.
- Основание: guideline.ru.minzdrav.654.v2.

<a id="case-internal-medicine-0006"></a>
## case.internal-medicine.0006: Гастроэзофагеальная рефлюксная болезнь без тревожных признаков

- Итог: **major-revision-required**.
- Ключевое исправление: нормальная ЭКГ не исключает ОКС при соответствующей клинике.
- Основание: guideline.ru.rga.gerd.2024.

<a id="case-internal-medicine-0007"></a>
## case.internal-medicine.0007: Острый неосложнённый цистит

- Итог: **major-revision-required**.
- Ключевое исправление: неопределённый антибиотик заменён схемой первой линии.
- Основание: guideline.ru.minzdrav.14.v3.

<a id="case-internal-medicine-0008"></a>
## case.internal-medicine.0008: Острый гастроэнтерит с дегидратацией

- Итог: **critical-revision-required**.
- Ключевое исправление: внутривенная жидкость сделана условной, а пероральная регидратация — базовой.
- Основание: guideline.int.who.diarrhoea.2005.

<a id="case-internal-medicine-0009"></a>
## case.internal-medicine.0009: Дефицит витамина D с признаками нарушения минерализации

- Итог: **critical-revision-required**.
- Ключевое исправление: низкая плотность кости не заменяет оценку остеомаляции и вторичных причин.
- Основание: guideline.ru.rae.vitamin-d.2021.

<a id="case-internal-medicine-0010"></a>
## case.internal-medicine.0010: Стойкая утомляемость неустановленной причины
