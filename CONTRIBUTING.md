# Внесение изменений

1. Редактируйте файлы в `data/`, а не сгенерированный runtime.
2. Для медицинского изменения укажите версию клинической рекомендации и обновите соответствующий аудит.
3. Не добавляйте исходные выгрузки, внешние идентификаторы происхождения или непроверенные коды справочников.
4. Выполните `npm run build`, затем `npm run validate`.
5. В описании изменения отделите структурную проверку от клинической приёмки.

Изменение правила считается клинически принятым только после документированной проверки профильным врачом. Одобрение кода или прохождение автоматического валидатора этого статуса не создаёт.
